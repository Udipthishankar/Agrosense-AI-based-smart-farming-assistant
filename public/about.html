About AgroSense

Our Mission

AgroSense is a farming information application with soil-based crop suitability matching, weather information, educational plant-condition references, local keyword-based guidance, and activity records.

Core Technologies

  • Crop suitability: A deterministic weighted score compares soil nutrients, pH, temperature, humidity, and rainfall with stored crop ranges.
  • Weather: Current weather information is requested from Open-Meteo when available.
  • Disease references: Built-in examples are educational and do not diagnose uploaded leaf images.
  • Farmer guidance: Chat responses are selected using local keyword rules.
  • Full-stack architecture: Built with React, Flask, and SQLite.
  • Interactive UI: Clean, mobile-friendly interfaces tailored for fast data entry in the field.
